# Calculadora de Pesos PWA

Proyecto ASP.NET Core 8 que sirve una PWA estática desde `wwwroot`.

## Visual Studio
Abra `CalculadoraPesosPWA.sln` y ejecute con Ctrl+F5.

## GitHub Pages
El workflow `.github/workflows/pages.yml` publica automáticamente `CalculadoraPesosPWA/wwwroot` cuando se hace push a `main`.

En GitHub configure:
Settings > Pages > Source > GitHub Actions.
